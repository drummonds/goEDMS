UI Components

Visual reference for godocs interface elements.

Document Card

The document card is the primary way documents are displayed in grid views. It shows a thumbnail or placeholder, action buttons, tags, filename, and document type.

Card Structure

  • Thumbnail (75% width) — clickable image or type placeholder linking to document view
  • Sidebar (25% width) — edit and select buttons, plus coloured tag chips (truncated to 7 characters)
  • Bottom row — filename (ellipsis overflow) and uppercase type badge

Variants

  • With thumbnail and multiple tags
  • Placeholder (no thumbnail) with single tag
  • With thumbnail, no tags
